# Rajasthan Royals SupeRR Selector (Season 2) — Interactive War Room Dashboard

Live Interactive Dashboard: [https://yashagarwal-lab.github.io/superrr-dashboard/](https://yashagarwal-lab.github.io/superrr-dashboard/)

An empirical sports-science and machine learning analytics platform identifying the most reliable players under pressure across 200,987 deliveries (883 matches, 141 competitions) and optimizing Rajasthan Royals' IPL 2027 Auction Strategy.

## Key Features
- **Modern Sports Analytics UI**: Clean Tailwind CSS / Shadcn UI / Tremor sports war room aesthetic without AI gradient slop.
- **Verified IPL 2027 Auction Intelligence**: Complete status coding for BCCI Ineligible (Pakistan benchmarks), Released Free Agents, Traded players (Kuldeep-Pant), and Core Retentions.
- **Unstop Top 10 Dropdown Filter**: 1-click filter for Unstop Top 10 Batters and Bowlers.
- **Dynamic Scatter Plots**: HTML5 Canvas inspection of Strike Rate / Economy vs. Clutch Success Rate (CSR) with interactive mouse hover tooltips.
- **Multi-Moment Radar Comparator**: Real-time 6-axis polygon overlay comparing any two players in the 394-player database across role optgroups.
- **Actionable Auction Target Board**: Strictly filtered to exclude untouchable retentions, RR core, and ineligible players, focusing purely on purchasable targets.
- **Royals Projected Starting XI Simulator**: Live calculation of squad clutch index and purse allocation within the ₹120.0 Cr cap (₹113.6 Cr spent / ₹6.4 Cr reserve).

Developed for Rajasthan Royals SupeRR Selector Season 2 by Yash Agarwal (@yashagarwal-lab).
