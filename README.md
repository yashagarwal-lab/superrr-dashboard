# Rajasthan Royals SupeRR Selector (Season 2) — Interactive War Room Dashboard

Live Interactive Dashboard: [https://yashagarwal-lab.github.io/superrr-dashboard/](https://yashagarwal-lab.github.io/superrr-dashboard/)

An empirical sports-science and machine learning analytics platform identifying the most reliable players under pressure across 200,987 deliveries (883 matches, 141 competitions) and optimizing Rajasthan Royals' IPL 2027 Auction Strategy.

## Key Features
- **Unstop Dropdown Filter**: 1-click filter for Top 10 Batters and Bowlers.
- **Dynamic Scatter Plots**: HTML5 Canvas inspection of Strike Rate / Economy vs. Clutch Success Rate (CSR).
- **Multi-Moment Radar Comparator**: Real-time 6-axis polygon overlay comparing any two players in the 394-player database.
- **Actionable Auction Target Board**: 56 Confirmed Released Free Agents & Eligible Global Scouting Steals categorized with price brackets.
- **Royals Projected Starting XI Simulator**: Live calculation of squad clutch index and purse allocation within the ₹120 Cr cap.

Developed for Rajasthan Royals SupeRR Selector Season 2 by Yash Agarwal (@yashagarwal-lab).
